GUARAMO — VERSÃO LOCAL DEMONSTRATIVA
=====================================

COMO ABRIR
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no VS Code.
3. Abra o arquivo index.html no navegador.
   (Opcional: use a extensão Live Server no VS Code.)

O QUE ESTA DEMONSTRAÇÃO FAZ
- Navegação responsiva entre as áreas públicas.
- Seletor de idioma: Português, Español e English.
- Cinco pontos de estoque, sem inventar nomes ou endereços reais.
- Área administrativa demonstrativa para adicionar, remover e definir quantidades.
- Estoque salvo somente no armazenamento local do navegador.
- Formulário demonstrativo de voluntariado com validação no navegador.
- Pedido de localização do navegador, sem consulta a uma base de serviços.
- Avisos sobre recursos que ainda dependem de integração.

IMPORTANTE — LIMITES
- Login admin / gu aramo123 é APENAS EXEMPLO local, não é autenticação segura.
- Não use dados pessoais ou documentos reais nesta demonstração.
- Formulários não são enviados para a administração.
- Não existe banco de dados, servidor, API, aprovação real de voluntários/documentos,
  busca real de vagas, geocodificação ou diretório de abrigos.
- Para uso real, é necessário backend seguro, autenticação, controle de acesso,
  armazenamento protegido de documentos, política de privacidade e validação jurídica.
- Textos em espanhol e inglês são TRADUÇÃO PARA REVISÃO.

IDENTIDADE VISUAL
Cores extraídas das referências previamente inspecionadas:
#EBEAC5, #A8433E, #D9D9D9, #FFFFFF, #F2E9E9 e preto.
A miniatura do .fig foi consultada, mas não permite recuperar todos os detalhes
de cada tela ou os fluxos originais. Esta versão é uma base funcional local,
não uma cópia pixel a pixel do Figma.
